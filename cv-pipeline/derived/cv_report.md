## Inter-assay CV -- standards-as-proxy (see caveat)
Standards-as-proxy inter-assay CV substitutes Standard1-6 Avg Result across plates for a true QC-pool inter-assay CV, because this dataset has essentially no repeated control data (only 1 of 8 cytokine plates has control wells; CRP has none at all). This is NOT equivalent to a proper inter-assay CV: standards are often reconstituted once per box and reused across several plates run the same day, so cross-plate agreement here can look artificially tight and may not capture true day-to-day or kit-lot variability. Treat as a rough indicative estimate, not a validated metric.
